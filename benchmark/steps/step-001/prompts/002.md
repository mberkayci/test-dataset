The project structure is hard to follow. Everything that belongs to
applications is spread across models/, schemas/, services/ and routers/,
and the tests live inside the app package.

Please reorganize the project by feature instead of by layer:
- Put everything that belongs to job applications into one package,
  app/applications/, with separate modules for the model, the schemas,
  the service logic and the router.
- Move shared infrastructure like the database setup into app/core/.
- Move the tests out of app/ into a top-level tests/ folder next to app/.
- Remove the old layer folders once they are empty.

Do not change any behavior. The API must work exactly as before and all
tests must still pass.
